Place ici le fichier de ton jeu (ex : jeu.zip).

Ce dossier est SERVI UNIQUEMENT via l'API /api/download, et seulement après
un paiement confirmé + un jeton de téléchargement valide.

⚠️ Ne mets JAMAIS le fichier du jeu dans /public : tout ce qui est dans /public
est téléchargeable librement, sans payer.

Par défaut, le serveur cherche le chemin défini par GAME_FILE_PATH dans .env.local
(valeur par défaut : ./protected/jeu.zip).
